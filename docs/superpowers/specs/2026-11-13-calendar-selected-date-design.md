# 日曆已選日期回饋

## 目的

使用者點擊日曆日期開啟操作選單後，仍能一眼辨識目前正在操作的日期；游標移到其他日期時，既有 hover 提示與底色仍可運作。

## 做法

- 點擊的日期保留一個短暫但持續的 `is-selected` 視覺狀態，直到選單關閉、改點另一個日期、切換月份或完成操作。
- 已選日期使用品牌色外框與淡色內底，不覆蓋休假、補班及手動標記本身的資訊。
- 已選與 hover 可以同時存在；選取樣式優先於一般 hover。
- 鍵盤開啟選單時套用相同狀態，並保持目前的 roving tabindex、焦點返回與 ARIA 行為。

## 不做的事

- 不把「選取」寫入月曆標記或備份。
- 不改變日期選單的操作、tooltip 資料或既有假日配色。
- 不帶入 Sheer 的小貓或其他客製需求。

## 替代方案

只加強 hover 無法在滑鼠離開後保留操作目標；永久記住最後點選日期則會讓使用者誤以為日期已被修改。因此採用選單生命週期內的暫態選取。

## 驗證

新增瀏覽器回歸測試，覆蓋滑鼠點擊、鍵盤開啟、切換不同日期、選單關閉與月份切換；確認 tooltip 與既有手動標記不受影響。
