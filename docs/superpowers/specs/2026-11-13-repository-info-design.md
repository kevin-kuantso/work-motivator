# Repository 資訊入口

## 目的

讓一般版使用者在主畫面與桌面版系統圖示選單找到專案來源與版本資訊，而不增加懸浮小窗負擔。

## 做法

- 主畫面頂欄新增具名稱的 GitHub 圖示按鈕，使用新分頁安全開啟一般版 repository。
- Windows 通知區／macOS 選單列的右鍵選單新增「關於」項目；它以原生對話框顯示一般版版本、資料僅留本機的說明，以及可直接開啟 repository 的按鈕。
- 文字依目前繁簡地區顯示；連結固定為 `https://github.com/kevin-kuantso/work-motivator`。

## 不做的事

- 不新增小窗入口。
- 不顯示或引用 Sheer 資訊。
- 不更動 GitHub repo 的 Social preview 設定。
